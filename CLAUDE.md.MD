# Toolshed – rules for Claude Code
- Read DESIGN_BRIEF.md before any work. It is the source of truth for design, colours, fonts and accessibility.
- Plain HTML/CSS/JS, no build step, no frameworks. Only MIT/OFL dependencies.
- Do ONE milestone per request, then stop and wait for my approval.
- Before finishing, open the page in a browser and check it yourself in dark and light mode, at desktop and phone width, and with reduced motion on.
- Commit after each milestone with a clear message (e.g. "M1: shell, design tokens, theme toggle").
- When something breaks, give me the one fix, not a redesign.

## Milestones
M1 Shell + design tokens + theme toggle + intro section
M2 3D category ring (scroll rotation, snap, click to open, keyboard, reduced-motion grid)
M3 Category view + search + data/tools.js (60+ tools across 15 categories)
M4 Image resize & compress tool
M5 PDF merge, reorder, remove/extract pages
M6 Polish pass + README + GitHub Pages
